# Atividades

Pequenos aplicativos de tela para atividades com crianças. Funcionam no navegador do computador e do celular, podem ser instalados na tela inicial e funcionam sem internet depois da primeira abertura.

| Atividade | Pasta |
|---|---|
| Cor e Número | [`cor-e-numero/`](cor-e-numero/) |
| Ficha e Número | [`ficha-e-numero/`](ficha-e-numero/) |

## Instalar no celular

- **Android (Chrome):** abra o link, toque no menu ⋮ e escolha **Instalar app** ou **Adicionar à tela inicial**.
- **iPhone (Safari):** abra o link, toque em **Compartilhar** e escolha **Adicionar à Tela de Início**.

## Nova atividade

Copie a pasta `cor-e-numero/` com outro nome, ajuste `index.html`, `manifest.webmanifest`, os ícones e o `VERSION` em `sw.js`, e adicione um link no `index.html` da raiz.

## Publicar uma alteração

O GitHub Pages publica automaticamente cada commit na branch `main`. Os aparelhos pegam a versão nova na próxima vez que abrirem o app com internet.
